Install

How to install StackGres

StackGres is designed to be extremely easy to install: type in just one command to have it installed via Helm and you'll have a production-ready/scripted installation.

Default settings are already set and there are options to customize it. For further information, please refer to the Install section on the StackGres Documentation.

This helm template is fully customizable. You may create your own values.yaml file. Check all the available parameters. Below is a simple form to help you quickly personalize some of the most common ones:

  • Default parameters
  • Customized parameters
