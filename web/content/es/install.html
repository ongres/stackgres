Instalación

Cómo instalar StackGres

StackGres está diseñado para ser extremadamente fácil de instalar: escribe un solo comando para instalarlo vía Helm y tendrás una instalación lista para producción y automatizable.

Los valores por defecto ya están configurados y existen opciones para personalizarlos. Para más información, consulta la sección de instalación en la }}">documentación de StackGres.

Esta plantilla de helm es totalmente personalizable. Puedes crear tu propio fichero values.yaml. Consulta todos los parámetros disponibles. A continuación tienes un sencillo formulario para personalizar rápidamente algunos de los más comunes:

  • Parámetros por defecto
  • Parámetros personalizados
  • helm install --create-namespace --namespace stackgres stackgres-operator --set-string adminui.service.type=LoadBalancer https://stackgres.io/downloads/stackgres-k8s/stackgres/latest/helm/stackgres-operator.tgz
